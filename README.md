# A Moment in the Cosmos

One verified photograph of the universe each day, with its story, scale, colours and credits.
Plain HTML, CSS and JavaScript modules. One build script, no dependencies.

```
npm run build    # validate data, then write dist/
npm run dev      # build, then serve dist/ at http://localhost:4173
npm run check    # validate the data files only
```

Vercel: `vercel.json` sets the build command (`node build.mjs`) and output folder (`dist`).

## Where things live

```
src/
  index.html            page shell: <head>, includes, one module script
  partials/             header, feature, discover, story, archive, favorites, about, footer, viewer
  css/main.css          import list; the order is the cascade (build inlines it to css/site.css)
  css/*.css             tokens, base, one file per component
  js/main.js            entry point; each module wires its own listeners
  js/feature.js         loads + verifies the photo, fires 'photo:change' for everything else
  js/compare.js         Hubble-vs-Webb slider
  js/tour.js            guided "look closer" tour (drives viewer.js flyTo)
  js/viewer.js          immersive pan/zoom viewer
  data/catalog.js       the 16 hand-curated photographs (labels, tours, comparisons)
  data/collection/      1,192 more (ESA/Hubble, ESA/Webb, ESO, NSF NOIRLab): index.json (id, category, title, thumbnail) + photos/<id>.json,
                        fetched on demand; generated by tools/harvest/export_collection.py
  data/schedule.js      daily rotation (append-only: it defines the archive)
  data/comparisons.js   ESA/Webb aligned image pairs, keyed by photograph id
  data/tours.js         tour stops (x/y in % of the image, zoom), keyed by photograph id
scripts/validate-data.mjs   runs in every build; bad data fails the build
scripts/serve.mjs           local static server
```

## Common edits

- **Add a tour:** an entry in `data/tours.js`. Only use positions the source caption describes.
- **Add a comparison:** an entry in `data/comparisons.js`. Use a pair the source publishes already aligned
  (same pixel size and framing), such as ESA/Webb's "Slider Tool" pages.
- **Add a photograph:** curated: a record in `data/catalog.js`, then append its id to `data/schedule.js`.
  Collection: see `tools/harvest/README.md` (the exporter appends to the schedule; never reorder it).
