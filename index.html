    About the collection

    How the daily photograph is chosen

    The featured photograph changes at 00:00 UTC and is the same for every visitor. The schedule rotates through Nebula, Galaxy, Night Sky and Star, and cycles through each category so no photograph repeats within days. Random browsing never changes the daily selection.

    The archive records each day’s selection from the page’s launch onward; it does not invent earlier history.

    Quality and verification

    • Real observatory imagery and landscape astrophotography only — no illustrations, simulations or AI-generated images.
    • Every displayed asset is at least 1,920 px on its long edge and 1,080 px on its short edge (1,440 × 1,440 for square images). Dimensions were measured from the actual files and are re-checked in your browser each time an image loads.
    • Nothing is upscaled. Immersive view can load the source’s full-resolution file on request.
    • “Recognition” reports only documented editorial selections (such as the ESA/Hubble and ESO “Top 100 Images” lists and anniversary releases). No sources used here publish audience ratings, so none are shown.

    Sources and permissions

    Images come from ESA/Hubble, ESA/Webb and ESO, all released under Creative Commons Attribution 4.0 with the full credit line shown beside each image. Files are loaded directly from each organisation’s public image servers; no API keys are required.

    NASA’s Astronomy Picture of the Day was reviewed but not integrated: its copyright varies image by image and its API needs a key, which would require a server to keep private. It can be added later through a server-side sourcing step.

    When something goes wrong

    If an image cannot be loaded from its source, or fails the size check, the page says so and shows a different, previously verified photograph from this collection — it never substitutes invented images, facts or credits. Capture dates, exposure details and filter colours that sources do not publish are marked as unavailable rather than guessed.
